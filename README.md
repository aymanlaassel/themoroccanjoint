# The Moroccan Joint

Static website for The Moroccan Joint, a halal Moroccan ghost kitchen in Miami.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `img/` — product photos and logo

Order links point to the existing Shopify product pages; the catering form and pre-order buttons open WhatsApp with the message pre-filled.

To preview locally, open `index.html` in a browser or run `python3 -m http.server` in this folder.
